== Description ==
Adds a new shortcode [testimonial_form] to allow visitors to submit testimonials via the front-end. This plugin was created for use with the Total theme but could technically work with any theme as the form simply inserts a new drafted post to the "testimonials" custom post type with some custom fields for the testimonial rating, company and url.

== Installation ==

1. Upload 'testimonial-submission-form-for-total' to the '/wp-content/plugins/' directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Insert the [testimonial_form] shortcode wherever you want the form to display or use the WPBakery plugin to insert the new Testimonial Form element to a page.
4. To prevent SPAM the plugin supports Google reCaptcha which you can setup in the Total theme under Theme Panel > reCaptcha.
